# Reverse an Array Using Pointers in C

## Description

This program reverses an array using two pointers, one pointing to the beginning and the other to the end. The elements are swapped until the array is reversed.

## Concepts Used

* Arrays
* Pointers
* Pointer arithmetic
* Swapping elements
* `while` loops

## How to Run

```bash
gcc reverse_array_pointers.c -o reverse_array_pointers.exe
./reverse_array_pointers.exe
```

## Language

C
